THE IDEA

Why do both sides get the same key?

Using modular arithmetic, Alice calculates Ba mod p and Bob calculates Ab mod p.

Since B = gb mod p and A = ga mod p, both results equal gab mod p.

Learning note: This simulator uses small numbers so the arithmetic is visible. Real systems use carefully selected large groups and authenticated key exchange. Basic Diffie–Hellman by itself does not prevent man-in-the-middle attacks.
